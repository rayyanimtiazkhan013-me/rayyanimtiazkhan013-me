System Architecture & Engineering Decisions

An in-depth explanation of how PillMind AI handles handwriting noise, state management across asynchronous webhooks, and scalable mobile deployment.

01

The Engineering Challenge

Medication non-adherence accounts for nearly 50% of treatment failures globally. Existing apps fail because they require manual data entry: typing complex medical names like "Levothyroxine 125mcg" and setting up tedious alarms.

PillMind AI eliminates friction by combining zero-click prescription vision intake with conversational multi-channel reminders (Telegram & WhatsApp) that fit existing messaging habits.

02

Multimodal Vision OCR Pipeline

Doctor handwriting is notoriously challenging for traditional OCR (Tesseract). We integrated Gemini 1.5 Vision LLM via n8n HTTP Request nodes with structured JSON schema enforcement.

{ "type": "OBJECT", "required": ["drug_name", "dosage_mg", "frequency_per_day"] }

This guarantees clean payload outputs even when processing low-contrast smartphone photos or crumpled prescriptions.

03

State Management & Cron Refill Logic

The n8n orchestrator runs a high-frequency Cron scheduler that checks active inventory tables. When stock drops below a configurable threshold (e.g. 5 remaining capsules):

  • Generates an auto-refill order payload.
  • Sends an instant interactive Telegram message with one-tap confirmation.
  • Escalates to SMS/Voice fallback if unanswered after 4 hours.
04

Commercialization & Google Play Roadmap

To transition from a prototype to a commercial healthcare product:

  • Flutter Mobile Client: Cross-platform Android/iOS app wrapped with local SQLite offline cache.
  • HIPAA / Data Privacy Layer: On-device encryption for sensitive patient health records.
  • Google Play Deployment: Packaging background push notification services for public release.
